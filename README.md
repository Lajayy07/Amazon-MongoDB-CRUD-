# MongoDB CRUD Application

## Amazon MongoDB CRUD Application

### amazon_review_crud.py

The `amazon_review_crud.py` program is a Python application that uses the PyMongo library to perform CRUD (Create, Read, Update, Delete) operations on the Amazon MongoDB database.

The program connects to the `Amazon` database and uses the `ReviewData` collection.

The application allows the user to:

- Query documents using `find_one()`
- Query multiple documents using `find()`
- Search by ReviewID
- Filter reviews by a user-entered number of stars
- Filter reviews using greater-than-or-equal-to criteria
- Filter reviews using less-than criteria
- Search for a word within the review title
- Search for a word within the review body
- Add new review documents
- Update fields within existing documents
- Delete a specific review document
- Delete all documents from the collection
- Delete the ReviewData collection
- Exit the program through a menu option

The application uses user input and a menu-driven interface to perform the required MongoDB CRUD operations.

### Database Information

Database: `Amazon`

Collection: `ReviewData`

Python Library: `PyMongo`

### Program File

`amazon_review_crud.py`
